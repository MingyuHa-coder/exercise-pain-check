# 운동 통증 점검 (exercise-pain-check)

헬스하다 어깨·허리·무릎이 아플 때, 5분 동안 질문에 답하면 **위험 신호 → 점검할 운동 변수 → 다음 운동에서 해볼 조정 → 전문가에게 확인받을 때**까지 안내하는 운동 상황 점검 웹앱입니다. 결과는 질환명이 아니라 무게·그립·깊이 같은 운동 변수로 보여줍니다. 기록은 이 기기의 브라우저에만 저장되고 어디로도 보내지 않습니다.

> ⚠️ **진단이나 치료가 아닙니다.** 아직 전문가 검토 전인 시제품입니다(검토 상태는 앱에서 주제·영역별로 표시). 통증이 계속되거나 심하면 정형외과나 재활의학과 진료를 받으세요.

- 스쿼트·런지·레그프레스 고관절 통증
- 바벨 로우 허리 통증

## 이 앱이 다른 점: 근거를 네 가지로 나눠 보여줍니다

| 표시 | 뜻 |
|---|---|
| 논문 확인 | 논문 본문에서 직접 확인한 결과 |
| 연구 종합 해석 | 여러 연구를 종합해서 내린 해석 |
| 앱 제안 | 연구를 바탕으로 앱이 권하는 실용적인 방법 |
| 검증 안 된 가설 | 앱이 세운 것으로, 아직 연구로 확인되지 않은 부분 |

본문을 직접 읽은 논문만 근거로 씁니다. "논문 확인" 아래에는 연구 종류와 대상(건강인인지, 통증 있는 사람인지)을 함께 붙입니다. 자세한 원칙은 [docs/evidence-principles.md](docs/evidence-principles.md)에 있습니다.

## 실행 방법

설치할 것이 없습니다. `index.html`을 브라우저로 열면 바로 실행됩니다.

## 파일 구성

화면·판단 규칙·콘텐츠를 나눠 두었습니다. 문구나 근거를 고칠 때는 `content/` 폴더만 보면 됩니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 틀. 아래 파일들을 순서대로 불러옴 |
| `css/app.css` | 화면 디자인 |
| `js/app.js` | 엔진: 화면 그리기, 진행 상태, 공통 판단 함수, 결과 기록 |
| `content/common.js` | 여러 주제가 함께 쓰는 위험 신호·질문·조정·출처 |
| `content/topics/*.js` | 주제별 콘텐츠: 버전, 위험 신호, 질문, 점검할 운동 변수, 조정, 판단 규칙(analyse), 근거 논문 |
| `content/body-map.js` | 운동 부위 → 운동 → 아픈 곳 → 주제 연결 |
| `content/glossary.js` | "쉬운 말 ↔ 의학 용어" 바꾸기 표 |
| `content/review-status.js` | 전문가 검토 상태: 7개 영역 × 5개 상태와 검토 기록 (기록된 검토 없음, 모두 검토 전) |
| `content/studies.js` | 연구별 종류·대상 (근거 수준 표시용) |
| `img/` | 벤치프레스 그립 너비 사진 (AI 생성 이미지) |
| `docs/*-plan.md` | 주제별 처음 기획 기록과 근거 논문 목록 (지금 앱 동작과 다른 부분이 있음) |
| `docs/evidence-principles.md` | 근거 표시 원칙 |
| `docs/expert-review-pending.md` | 전문가 검토가 필요한 자체 설계 목록과 검토 기록 |
| `docs/rule-inventory.md` | 판단 규칙·점수·진료 시점 전체 목록과 분류, 내부 보존 자료(질환명·진단 관련 문장) |
| `docs/data-privacy.md` | 저장하는 정보, 저장 형식, 삭제, 서버·계정 확장 때 필요한 것 |
| `docs/c11-review-cases.md` | C11(진료 먼저 조건과 운동 조정) 전문가 검토 사례 |
| `tests/` | 자동 테스트 (`node tests/run-tests.js`, 사용법은 tests/README.md) |
| `docs/user-wording-changes.md` | 사용자 문구에서 질환명·진단 표현을 고친 전후 기록과 원래 연구 대상 |
| `docs/expert-review-request-by-role.md` | 의사·물리치료사·스포츠과학 전문가·트레이너별 검토 요청서 |

주제 파일 이름: `bench` 벤치 어깨, `ohp` 숄더 프레스 어깨, `dl` 데드리프트 허리, `sqk` 하체 무릎, `sqb` 스쿼트 허리, `lat` 레터럴 레이즈 어깨, `elb` 팔꿈치, `wri` 손목, `run` 달리기, `dps` 딥스·푸시업 어깨, `pul` 풀업·랫풀다운 어깨, `hip` 고관절, `row` 바벨 로우 허리.

## 앞으로

- 전문가 검토 받기
- 운동 주제 늘리기
- 운동 지도 전문가(트레이너, 운동처방·스포츠과학 전문가) 연결은 법률 검토 후 별도로 검토
- 의료기관은 "정형외과·재활의학과에서 확인받으세요"처럼 일반적인 안내만 하고, 병원 추천·순위·예약·중개·광고는 하지 않음
