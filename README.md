# 운동 통증 점검 (exercise-pain-check)

헬스하다 어깨·허리·무릎이 아플 때, 5분 동안 질문에 답하면 **위험 신호 → 통증 패턴 → 바로 해볼 조정 → 전문가 연결**까지 안내하는 자가점검 웹앱입니다.

> ⚠️ **진단이나 치료가 아닙니다.** 아직 전문가 검토 전인 시제품입니다. 통증이 계속되거나 심하면 의사나 물리치료사의 진료를 받으세요.

## 지금 있는 주제

- 벤치프레스 어깨 통증
- 숄더 프레스 어깨 통증
- 데드리프트 허리 통증
- 스쿼트·런지·레그프레스 무릎 통증
- 스쿼트 허리 통증
- 레터럴 레이즈·업라이트 로우 어깨 통증
- 컬·풀업 팔꿈치 통증

## 이 앱이 다른 점: 근거를 네 가지로 나눠 보여줍니다

| 표시 | 뜻 |
|---|---|
| 논문 확인 | 논문 본문에서 직접 확인한 결과 |
| 연구 종합 해석 | 여러 연구를 종합해서 내린 해석 |
| 앱 제안 | 연구를 바탕으로 앱이 권하는 실용적인 방법 |
| 검증 안 된 가설 | 앱이 세운 것으로, 아직 연구로 확인되지 않은 부분 |

본문을 직접 읽은 논문만 근거로 씁니다. 자세한 원칙은 [docs/evidence-principles.md](docs/evidence-principles.md)에 있습니다.

## 실행 방법

설치할 것이 없습니다. `index.html`을 브라우저로 열면 바로 실행됩니다.
