# 전문가 검토 요청서 (역할별)

Nov 6, 2026 · @하민규

## 이 문서를 읽는 법

**앱 소개.** 헬스하다 아픈 사람이 운동 부위 → 운동 → 아픈 곳을 고르고 10개 안팎 질문에 답하면, (1) 위험 신호가 있으면 진료를 안내하고 (2) 없으면 "가장 가까운 패턴"과 운동 조정 세 가지를 보여주는 자가점검 앱이다. 진단이 아니라 운동 참고 정보다. 현재 13개 주제(어깨 5, 허리 3, 무릎 2, 고관절·팔꿈치·손목 각 1)다.

**왜 검토가 필요한가.** 앱의 모든 문장은 네 가지로 나눠 표시한다: 논문 확인 / 연구 종합 해석 / 앱 제안 / 검증 안 된 가설. 여기 적은 항목은 논문이 아니라 앱이 정한 부분이다(기준값, 시간 표현, 질문 문구, 패턴을 고르는 규칙 등). 표시가 없는 일반 허리·어깨 항목 일부는 이미 검토를 마쳤다.

**표시.** 🔴 결과에 직접 영향(반드시) · 🟡 표현·예시(가볍게). 항목 번호는 주제 약자다: C 공통, B 벤치 어깨, O 숙더 프레스, L 레터럴 레이즈, P 딥스·푸시업, U 풀업, D 데드리프트, Q 스쿼트 허리, X 바벨 로우, K 무릎, H 고관절, R 달리기, E 팔꿈치, W 손목.

**답변 방법.** 각 항목에 아래 세 가지 중 하나로 답해 주세요. 문서에 바로 댓글로 달아도 됩니다. 자세한 근거는 전체 "전문가 검토 대기 목록"에 있습니다.

| 답 | 뜻 |
| --- | --- |
| ✅ 그대로 | 지금 내용이 적절함 |
| ✏️ 고침 | 어떻게 바꾸면 좋을지 한두 줄 |
| ❌ 빼기 | 앱에서 없애는 게 낫다 |

역할이 겹치는 항목은 한 곳에만 적었다. 자기 분야가 아니어도 의견이 있으면 환영한다.

## 의사 (정형외과·재활의학과)

**확인해 주실 것: 위험 신호를 빠뜨리지 않았는지, 진료를 권하는 시점과 문구가 맞는지.** 앱은 위험 신호를 "지금 바로 응급실 / 오늘 / 며칠 안 / 빠른 시일 내" 네 단계로 안내한다. 이 단계 구분과 일반인용 질문 문구는 대부분 앱이 정했다.

| 항목 | 질문 |
| --- | --- |
| 🔴 D1, X4 | 허리: 마미증후군·진행성 약화 → 지금 응급실, 골절·감염 → 오늘, 암·다리 저림 → 빠른 진료. 단계가 맞나? (로우도 같은 기준) |
| 🔴 K1, W1, R1, E2, P1 | 무릎 인대·반월상연골, 주상골 골절, 피로골절, 이두근·대흉근 파열을 "오늘" 또는 "며칠 안"으로 나눈 것이 맞나? |
| 🔴 H1, E1, U1 | 고관절 6문항(외상·감염·피로골절·비뇨기/복부·허리 신경·체중 감소), 팔꿈치 골절·감염, 날개뼈 돌출(긴가슴신경). 빠진 신호나 지나친 신호가 있나? |
| 🔴 R2 | "피로골절 과거력, 생리가 몇 달째 없음" → 빠른 진료. 몇 개월을 기준으로, 어떤 표현으로 물을까? |
| 🔴 C6, O7 | 위험 신호를 일반인이 정확히 답할 수 있는 문구인가? (예: "다친 뒤 아프지 않은데도 팔을 어깨 높이 위로 들 힘이 없나요?") |
| 🔴 C3, C4 | 조정 2주 뒤에도 그대로면 진료, 일상에서도 아픔·나빠짐·6주 이상이면 조정보다 진료 먼저. 기준이 너무 빠르거나 느리지 않은가? |
| 🔴 D2, U2, H3 | "무릎 아래 다리 저림", "어깨가 빠질 것 같은 느낌", "고관절 딸깍·걸림·잠김"이면 운동 조정 없이 진료 먼저. 지나치게 보수적인가? |
| 🔴 K4, P7 · 🟡 W2, H4 | "진료 먼저"로 보낸 통증(무릎 안·바깥쪽·붓기, 손목 옆·손바닥 쪽, 엉덩이 바깥쪽)과 조정으로 다룬 통증(가슴·겨드랑이 앞 근육). 바꿔야 할 것이 있나? |

## 물리치료사

**확인해 주실 것: 스스로 답한 내용만으로 패턴을 나눠도 되는지, 재활 운동 예시와 스스로 해 보는 동작이 안전한지.** 앱은 답변마다 점수를 주고 가장 높은 패턴을 고른다. 점수 크기와 기준선은 모두 앱이 정했고, 논문 대부분은 진찰(누름 통증·특수 검사)을 기준으로 한다.

| 항목 | 질문 |
| --- | --- |
| 🔴 C1, C2 | 점수로 패턴을 고르고 조정 상위 3개만 보여주는 방식 자체가 타당한가? |
| 🔴 K3, R3, H2, E3 | 무릎(슬개대퇴 vs 슬개건), 달리기(아픈 위치만으로 4패턴), 고관절(관절 vs 내전근 vs 장요근), 팔꿈치(바깥 vs 안쪽)를 자가 응답으로 나눠도 되나? |
| 🔴 L4, P2, U3, X1, O4 | 건강인 동작 측정 연구를 "이 동작에서 아프면 이 부담" 패턴으로 연결한 규칙(업라이트 로우, 깊은 딥스, 목 뒤·넓은 그립 풀업, 숙인 로우, 목 뒤 프레스) |
| 🔴 B1 | 상완골 전방활주 안내 카드: 단서 4개 중 3개 이상이면 띄우는 기준 |
| 🔴 O1, O3 | 앱이 만든 "벽에 기대 팔 올리기" 확인 동작. 아픈 사람에게 직접 해 보게 해도 되나, "아프면 멈추세요"로 충분한가? |
| 🔴 D5, Q1 | 물리치료사가 지도한 데드리프트 프로그램(Michaelson 2016)을 혼자 하도록 안내하고, 스쿼트에도 옮긴 것 |
| 🟡 R6, H7, P6 | 근력 운동 예시(옆으로 누워 다리 들기, 밴드 옆걸음, 브릿지, 플랭크, 푸시업 플러스)와 "주 2\~3회·3개월" 빈도 |
| 🟡 P3, U7 | 딥스·풀업의 쇄골 끝 통증 패턴에 벤치 연구를 옮긴 것 |

## 스포츠과학 전문가

**확인해 주실 것: 동작·그립·깊이·부하를 바꾸는 조정이 헬스장에서 현실적이고 정확한지.** 조정의 수치와 표현("평행 전까지", "45° 정도", "어깨너비보다 조금 넓게")은 대부분 건강인 연구를 바탕으로 앱이 쉽게 바꾼 것이고, 통증이 줄어드는지는 연구되지 않았다.

| 항목 | 질문 |
| --- | --- |
| 🔴 R4 | "한 번에 지난 한 달 최장 거리를 넘지 않게" (건강한 러너 5,205명 관찰 연구)를 아픈 사람의 복귀 기준으로 써도 되나? |
| 🔴 D4, B2 | 훈련 부하 급증 패턴("최근 4주 크게 늘림", 주 3회 이상)과 벤치 그립·1RM 점수 배분 |
| 🟡 P4, P5, U4 | 딥스 "위팔이 바닥과 평행해지기 전까지", 푸시업 팔꿈치 "45° 정도", 풀업 손 간격 "어깨너비보다 조금 넓게" |
| 🟡 U5, U6 | 아픈 동안 도움받는 풀업·랫풀다운으로 바꾸기, 맨 아래에서 힘을 준 채 매달리기 |
| 🟡 H5, H6 | 스쿼트 깊이를 박스로 제한, 발 간격·발끝 방향 조절, 와이드·큰 보폭 런지 줄이기 |
| 🟡 X2, X3 | 서서 하는 바벨 로우 → 가슴 받침·한 손 짚기·앉은 로우로 바꾸기, 반동 없이 상체 고정 |
| 🟡 R5, R7 | 발걸음 수 5\~10% 늘리기, 정강이 부목에 다른 유산소로 대신하기 |
| 🟡 W3, W4, W5 | 손목을 덜 꺾는 방법(바 위치·푸시업 손잡이·주먹), 선수 리뷰를 헬스인에게 옮긴 것과 "2주", 손목 랩 안내 |

답변을 받으면 앱에 반영하고, 검토를 마친 항목에는 "전문가 검토 완료", 고친 항목에는 "전문가 검토 의견 반영" 표시를 붙인다.
