# 전문가 검토 요청서 (역할별)

Nov 6, 2026 · @하민규

## 이 문서를 읽는 법

**앱 소개.** 헬스하다 아픈 사람이 운동 부위 → 운동 → 아픈 곳을 고르고 10개 안팎 질문에 답하면, (1) 위험 신호가 있으면 진료를 안내하고 (2) 없으면 "점검할 운동 변수"(예: 그립 너비, 앉는 깊이, 최근 훈련량)와 다음 운동에서 해볼 조정 세 가지를 보여주는 운동 상황 점검 앱이다. 질환명을 판정하지 않고, 진단이 아니라 운동 참고 정보다. 사용자에게 검사 동작을 직접 해 보게 하지 않고 이미 겪은 상황만 묻는다. 현재 13개 주제(어깨 5, 허리 3, 무릎 2, 고관절·팔꿈치·손목 각 1)다.

**왜 검토가 필요한가.** 앱의 모든 문장은 네 가지로 나눠 표시한다: 논문 확인 / 연구 종합 해석 / 앱 제안 / 검증 안 된 가설. 여기 적은 항목은 논문이 아니라 앱이 정한 부분이다(기준값, 시간 표현, 질문 문구, 점검 변수를 고르는 규칙 등). **지금 앱의 모든 내용은 검토 전이다.** 위 역할별 표에 없는 항목은 맨 아래 "추가 검토 항목"에 모았다.

**표시.** 🔴 결과에 직접 영향(반드시) · 🟡 표현·예시(가볍게). 항목 번호는 주제 약자다: C 공통, B 벤치 어깨, O 숄더 프레스, L 레터럴 레이즈, P 딥스·푸시업, U 풀업, D 데드리프트, Q 스쿼트 허리, X 바벨 로우, K 무릎, H 고관절, R 달리기, E 팔꿈치, W 손목.

**답변 방법.** 각 표의 "앱이 보여주는 것"은 앱 화면에 실제로 나오는 질문·안내 문구다. 맨 오른쪽 "답" 칸에 아래 세 가지 중 하나를 적어 주세요. 문서에 바로 댓글로 달아도 됩니다. 자세한 근거는 전체 "전문가 검토 대기 목록"에 있습니다. 검토해 주신 분의 **자격과 전문 분야**를 맨 위에 한 줄 적어 주세요(검토 기록에 남깁니다).

| 답 | 뜻 |
| --- | --- |
| ✅ 그대로 | 지금 내용이 적절함 |
| ✏️ 고침 | 어떻게 바꾸면 좋을지 한두 줄 |
| ❌ 빼기 | 앱에서 없애는 게 낫다 |

역할이 겹치는 항목은 한 곳에만 적었다. 자기 분야가 아니어도 의견이 있으면 환영한다. 🔴 항목(위험 신호·진료 안내·결과 규칙)은 가능하면 두 분 이상에게 따로 받고, 의견이 다르면 더 보수적인 쪽을 따른다.

## 의사 (정형외과·재활의학과)

**확인해 주실 것: 위험 신호를 빠뜨리지 않았는지, 진료를 권하는 시점과 문구가 맞는지.** 앱은 위험 신호에 "예"가 하나라도 있으면 바로 아래 네 단계 중 하나를 띄운다: ① 지금 바로 응급실(119) ② 오늘 진료·응급실 ③ 며칠 안에 정형외과 ④ 빠른 시일 내 진료. 단계 배정과 질문 문구는 대부분 앱이 정했다.

## 물리치료사

**확인해 주실 것: 스스로 답한 내용만으로 점검할 운동 변수를 골라도 되는지, 일반적인 운동 방법 예시가 적절한지.** 앱은 답변마다 점수를 주고 가장 높은 운동 변수를 "먼저 점검할 것"으로 보여준다(예전의 "가장 가까운 패턴"). 점수와 기준선은 앱이 정했고, 논문 대부분은 진찰(누름 통증·특수 검사)이나 건강인 동작 측정이 기준이다. 연구에서 쓰는 이름(예: 회전근개 관련 통증)과 진단 가능성 문장은 v8부터 사용자 화면에 보여주지 않고 내부 검토 자료(`docs/rule-inventory.md`)에만 둔다.

| 항목 | 앱이 보여주는 것 (실제 문구) | 확인해 주실 점 | 답 |
| --- | --- | --- | --- |
| 🔴 C1 전 주제 공통 | 답변마다 +1\~+4점을 주고 점수가 가장 높은 운동 변수를 "먼저 점검할 것"(예: "팔을 머리 위로 올리는 구간의 어깨 부담"), 3점 이상을 "함께 점검할 것"으로 보여줌. 카드마다 "점검할 운동 변수" 목록(예: 무게와 횟수, 그립 너비)이 붙음 | 자가 응답 점수로 점검할 변수를 고르는 방식이 타당한가? |  |
| 🔴 C9 전 주제 공통 | (v7 기준 점수 제거) 어떤 답변도 해당하지 않는 변수는 결과에서 빼고, 맨 앞 변수가 빠지면 "현재 답변만으로는 우선적으로 점검할 변수를 좁히기 어려워요" 안내. 남는 변수가 없으면 조정도 권하지 않음 | 모호한 답에 이렇게 보여주는 게 맞나? |  |

| 🔴 C2 전 주제 공통 | 조건에 맞는 조정 중 우선순위 상위 3개만 "이번 주 해 볼 조정"으로 보여줌 | 3개가 적당한가, 순서를 어떻게 정해야 하나? |  |
