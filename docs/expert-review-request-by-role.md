# 전문가 검토 요청서 (역할별)

Nov 6, 2026 · @하민규

## 이 문서를 읽는 법

**앱 소개.** 헬스하다 아픈 사람이 운동 부위 → 운동 → 아픈 곳을 고르고 10개 안팎 질문에 답하면, (1) 위험 신호가 있으면 진료를 안내하고 (2) 없으면 "가장 가까운 패턴"과 운동 조정 세 가지를 보여주는 자가점검 앱이다. 진단이 아니라 운동 참고 정보다. 현재 13개 주제(어깨 5, 허리 3, 무릎 2, 고관절·팔꿈치·손목 각 1)다.

**왜 검토가 필요한가.** 앱의 모든 문장은 네 가지로 나눠 표시한다: 논문 확인 / 연구 종합 해석 / 앱 제안 / 검증 안 된 가설. 여기 적은 항목은 논문이 아니라 앱이 정한 부분이다(기준값, 시간 표현, 질문 문구, 패턴을 고르는 규칙 등). 표시가 없는 일반 허리·어깨 항목 일부는 이미 검토를 마쳤다.

**표시.** 🔴 결과에 직접 영향(반드시) · 🟡 표현·예시(가볍게). 항목 번호는 주제 약자다: C 공통, B 벤치 어깨, O 숙더 프레스, L 레터럴 레이즈, P 딥스·푸시업, U 풀업, D 데드리프트, Q 스쿼트 허리, X 바벨 로우, K 무릎, H 고관절, R 달리기, E 팔꿈치, W 손목.

**답변 방법.** 각 표의 "앱이 보여주는 것"은 앱 화면에 실제로 나오는 질문·안내 문구다. 맨 오른쪽 "답" 칸에 아래 세 가지 중 하나를 적어 주세요. 문서에 바로 댓글로 달아도 됩니다. 자세한 근거는 전체 "전문가 검토 대기 목록"에 있습니다.

| 답 | 뜻 |
| --- | --- |
| ✅ 그대로 | 지금 내용이 적절함 |

## 의사 (정형외과·재활의학과)

## 물리치료사

**확인해 주실 것: 스스로 답한 내용만으로 패턴을 나눠도 되는지, 재활 운동 예시와 스스로 해 보는 동작이 안전한지.** 앱은 답변마다 점수를 주고 가장 높은 패턴을 "가장 가까운 패턴"으로 보여준다. 점수와 기준선은 앱이 정했고, 논문 대부분은 진찰(누름 통증·특수 검사)이나 건강인 동작 측정이 기준이다.

| 🔴 C1 전 주제 공통 | 답변마다 +1\~+4점을 주고 점수가 가장 높은 패턴을 "앱이 본 패턴"으로, 3점 이상인 패턴을 함께 보여줌 | 자가 응답 점수로 패턴을 고르는 방식이 타당한가? |  |
