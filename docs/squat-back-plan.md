## 개요와 위험 신호

스쿼트 허리 통증은 데드리프트 허리 기획서의 위험 신호 6개, 패턴 3개(비특이적 허리 통증·신경 뿌리 자극 가능성·훈련 부하 급증), 전문가 연결 기준을 그대로 쓴다. 다른 것은 스쿼트만의 단서인 깊이, 가장 깊이 앉을 때 골반이 말리는지(벗윙크), 바 위치다.

- **논문 확인**: 파워리프터 부상의 42%가 스쿼트 훈련 중 시작됐고, 허리·골반이 가장 흔한 부위였다. 다만 허리·골반 부상과 뚜렷하게 연결된 종목은 데드리프트였다 ([Strömbäck 2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC5954586/)).
- 위험 신호 근거는 [데드리프트 허리 기획서](https://claude.ai/artifact/6ZAKUAXUKRtxW5CWdNcyvU)와 같다 (Finucane 2020).

## 증상 질문과 패턴

| # | 질문 | 선택지 | 어디에 쓰이나 |
| --- | --- | --- | --- |
| 1 | 어디가 아픈가요? | 허리 가운데·양옆 / 한쪽 엉덩이 / 잘 모름 | 패턴 설명 |
| 2 | 다리로 통증·저림이 내려가나요? | 없음 / 허벅지까지 / 무릎 아래·발까지 | 무릎 아래 → 진료 먼저 |
| 3 | 언제 가장 아픈가요? | 가장 깊이 앉았을 때 / 일어설 때 / 운동 후·다음 날 / 일상에서도 | 깊이 조정, 일상 → 진료 먼저 |
| 4 | 가장 깊이 앉을 때 골반이 말리며 허리가 둥글게 되나요? | 예 / 아니오 / 모름 | 깊이 조정 |
| 5 | 어떤 스쿼트를 주로 하나요? | 바벨 백(바 높게) / 바벨 백(바 낮게) / 프런트·고블릿 | 프런트·고블릿 추천 |
| 6 | 최근 4주 사이 무게나 횟수를 크게 늘렸나요? | 예 / 아니오 | 부하 관리 |
| 7 | 아프고 나서 스쿼트는? | 아예 쉼 / 가볍게 계속 / 원래대로 | "다시 서서히" 추천 |
| 8 | 시작 | "삐끗" / 서서히 | 급성 여부 |
| 9·10 | 기간, 경과 | 데드리프트와 같음 | 전문가 연결 |

패턴은 데드리프트와 같은 3개를 쓴다.

- **논문 확인**: 엉덩이가 굽힐 수 있는 끝에 닿으면 골반이 뒤로 말리고, 이때 허리도 함께 굽혀져 허리에 압박·전단력이 걸린다. 무릎 90° 넘게 앉아도 허리 근육 활성도는 더 늘지 않아, 인대 같은 구조물이 버틴다고 본다 ([Straub & Powers 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC10987311/), 임상 해설).
- **검증 안 된 가설**: 골반 말림(4번)을 사용자가 스스로 알 수 있는지, 그것이 통증과 관련이 있는지는 확인되지 않았다. 허리 굽힘 자체의 양쪽 근거는 데드리프트 기획서의 "허리 굽힘: 양쪽 근거"를 그대로 쓴다.

## 조정과 전문가 연결

| 조정 (앱 제안) | 추천 조건 | 논문 확인 | 검증 안 된 가설 | 강도 |
| --- | --- | --- | --- | --- |
| 무게와 횟수 낮추기 | 6번 예, 또는 7번 원래대로 | 파워리프터 부상자 대부분은 훈련량·강도를 줄이며 훈련을 이어갔다 (Strömbäck 2018) | "2주"는 앱의 값 | 약함 |
| 끊지 말고 가볍게 다시 늘리기 | 7번 쉼·가볍게 | 평소 활동 지속을 권한다 (NICE NG59). 데드리프트로는 통증에 맞춘 점진 부하가 효과가 있었다 (Michaelson 2016) | 스쿼트로 같은 방법을 시험한 연구는 없다. 데드리프트 연구를 스쿼트로 옮긴 것은 앱의 추론 | 약함 |
| 허리가 둥글어지기 전까지만 앉기 | 4번 예, 3번 "가장 깊이" | 저자들은 허리 통증이 있으면 허리를 중립으로 유지할 수 있는 깊이까지만 앉으라고 권한다 (Straub & Powers 2024, 임상 해설) | 통증이 줄어드는지는 연구되지 않음 | 약함 |
| 프런트·고블릿 스쿼트로 바꾸기 | 5번 백 스쿼트 | 무게를 몸 앞에 두면 상체가 더 서고, 백 스쿼트는 같은 무게에서 엉덩이 부담이 더 컸다. 저자들은 허리 통증에 상체를 덜 숙이도록 발을 조금 넓게 서는 것도 권한다 (Straub & Powers 2024) | 허리 통증이 줄어드는지는 확인되지 않음. 무게는 더 가볍게 시작해야 함 | 약함 |
| 다른 운동으로 계속 움직이기 | 7번 쉼 | 평소 활동 지속·운동 프로그램을 권한다 (NICE NG59) | 운동 예시는 앱의 선택 | 중간 |

전문가 연결 기준은 데드리프트 허리와 같다: 다리 증상(무릎 아래), 일상 통증, 6주 이상, 나빠짐이면 진료 먼저.
