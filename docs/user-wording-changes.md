# 사용자 문구 변경 기록 (콘텐츠 버전 8.1)

결과 카드·조정 카드·설명 카드·카드 제목·연구 대상 표시에서 질환을 진단하거나 의심하는 것으로 읽힐 수 있는 문장을 고친 기록이다. **이 문서는 내부 검토 자료다.** 논문에서 쓴 질환명과 정확한 연구 대상은 여기와 각 데이터 파일의 내부 필드에 보존한다.

## 고친 원칙

1. 사용자 화면은 운동 상황, 증상, 조정할 수 있는 운동 변수를 중심으로 쓴다.
2. 질환명이 연구 대상이었던 문장은 "진료에서 ~로 분류된 사람", "진찰로 ~이 확인된 사람"처럼 **연구 대상이 진료로 분류·확인된 사람이었다는 점**을 남긴다. "무릎 앞이 아픈 사람"처럼 대상을 실제보다 넓히지 않는다.
3. 근거 출처, 연구 종류, 연구 대상(인원), "통증 있는 사람 대상 / 건강인 등에서 옮김 / 진료 지침" 구분은 그대로 둔다.
4. 연구 결과의 수치와 결론은 바꾸지 않는다.
