# 숄더 프레스 어깨 통증 자가점검 기획서

> **안내 (콘텐츠 버전 8.1):** 이 문서는 주제를 처음 만들 때의 기획 기록이다. 지금 앱은 질환명 대신 운동 변수로 결과를 보여주고, "2주" 같은 기간을 권하지 않으며, 모든 내용이 전문가 검토 전이다. 현재 판단 규칙은 [rule-inventory.md](rule-inventory.md), 사용자 문구 변경은 [user-wording-changes.md](user-wording-changes.md)를 따른다.

Nov 5, 2026 · @하민규

## 개요

두 번째 주제는 "숄더 프레스할 때 어깨가 아프다"이다. 화면 흐름(위험 신호 → 증상 질문 → 패턴 → 조정과 기록 → 전문가)과 안전 원칙은 벤치 어깨 기능을 그대로 쓰고, 질문·패턴·조정만 바꾼다.

|  | 벤치 어깨 | 숄더 프레스 어깨 |
| --- | --- | --- |
| 주로 아픈 구간 | 바를 가슴까지 내릴 때 | 팔을 머리 위로 올리는 중간 높이, 끝까지 밀 때 |
| 핵심 단서 | 그립 너비, 팔꿈치 각도, 고중량 | 아픈 높이(통증 호), 뒤로 내리는지, 허리 젖힘 |
| 숄더 프레스만 다룬 연구 | 근골격 모델 연구 1편 (Noteboom 2024) | 동작 분석 연구 1편 (McKean 2015) |

숄더 프레스를 직접 다룬 연구가 적어서, 어깨 충돌성 통증과 견갑 연구를 머리 위 동작에 맞게 적용한 부분이 많다. 그만큼 근거 강도를 보수적으로 표시한다.

## 1단계: 위험 신호

벤치의 6문항을 그대로 쓰고, 머리 위 동작에서 중요한 두 항목을 바꾼다. 대흉근 파열 문항 대신 급성 회전근개 파열 문항을 넣는다.

| 질문 (예/아니오) | 의심되는 상황 | 앱 안내 |
| --- | --- | --- |
| 가슴 답답함, 숨참, 식은땀과 함께 어깨·팔이 아픈가요? | 심장·폐 | 즉시 119 |
| 어깨가 빠진 느낌이 들거나 모양이 변했나요? | 탈구 | 오늘 응급실 |
| 열이 나거나 어깨가 붉고 뜨겁게 부었나요? | 관절 감염 | 오늘 응급실 |
| 무게를 들다가 다친 뒤, 아프지 않은데도 팔을 어깨 높이 위로 들 힘이 없나요? | 급성 회전근개 파열 | 며칠 안에 정형외과 |
| 쉬어도 밤새 계속 아프거나, 혹이 만져지거나, 이유 없이 살이 빠졌나요? | 종양 등 | 빠른 시일 내 진료 |
| 팔이나 손이 저리거나, 통증이 팔꿈치 아래까지 내려가나요? | 목에서 오는 통증 | 진료로 원인 확인 |

- 영국 1차 진료 요약은 급성 회전근개 파열을 "쉽게 놓치는" 위험 신호로 보고, 특히 통증보다 힘이 없어서 팔을 어깨 위로 못 드는 경우를 강조한다 ([KISS 1차 진료 요약](https://api.nbmedical.com/file/28a1e6ed-f590-4136-9cd5-3fc1b2f04263/kiss-shoulder-pain.pdf)). 외상 후 급성 회전근개 파열은 긴급 의뢰 대상이다 ([BESS/BOA, Rees 2021](https://pmc.ncbi.nlm.nih.gov/articles/PMC7905504)).
- 나머지 항목의 근거와 한계는 벤치 어깨 기획서와 같다.

## 2단계: 증상 질문

질문 10개로 아픈 위치와 높이, 숄더 프레스 방식을 받는다. 벤치와 같은 기간·경과·보조운동 문항은 그대로 쓴다.

| # | 질문 | 선택지 | 어디에 쓰이나 |
| --- | --- | --- | --- |
| 1 | 어디가 아픈가요? | 어깨 앞·옆(삼각근 부위) / 어깨 위쪽 한 점(쇄골 끝) / 목과 어깨 사이 / 잘 모름 | 앞·옆 → 회전근개, 위쪽 → 쇄골 끝, 목 → 뒤로 내리기·목 부담 |
| 2 | 팔을 옆으로 천천히 들어 올릴 때 언제 아픈가요? (직접 해 보기) | 어깨 높이 전후 중간에서만 / 끝까지 올렸을 때만 / 올리는 내내 / 안 아픔 | 중간만 → 통증 호(회전근개), 끝 → 쇄골 끝 |
| 3 | 어떤 숄더 프레스를 하나요? | 바벨 앞으로 / 바벨 뒤로(목 뒤) / 덤벨 / 머신 | 뒤로 → 앞으로 바꾸기 추천 |
| 3-1 | 바벨 손 간격은? (추가) | 어깨너비 정도 / 1.4배쯤 / 그보다 넓게 / 바벨 안 씀 | 넓게 → 그립 중간 너비 조정 |
| 4 | 아픈 쪽으로 누우면 아픈가요? | 예 / 아니오 | 예 → 회전근개 |
| 5 | 위로 밀 때 허리가 크게 젖혀지나요? | 예 / 아니오 / 모름 | 예·모름 → 몸통 고정 |
| 6 | 벽에 등을 대고 서서 허리를 떼지 않고 두 팔을 머리 위로 올려 벽에 닿일 수 있나요? (직접 해 보기) | 쉽게 닿음 / 간신히 / 안 닿음 | 안 닿음 → 등 펴기·가동성 |
| 7 | 밀어 올릴 때 어깨가 귀 쪽으로 솟나요? | 예 / 아니오 / 모름 | 예 → 날개뼈 |
| 8 | 아픈 지 얼마나 됐나요? | 2주 미만 / 2\~6주 / 6주 이상 | 전문가 연결 |
| 9 | 요즘 통증은? | 좋아짐 / 그대로 / 나빠짐 | 전문가 연결 |
| 10 | 보조운동을 하나요? | 정기적 / 가끔 / 안 함 | 보조운동 추천 |

2번과 6번은 사용자가 직접 동작을 해 보는 문항이다. 아프면 멈추라는 안내를 함께 넣는다. 6번은 앱이 만든 간단한 확인 동작이며, 검증된 검사가 아니다.

## 3단계: 패턴 안내

머리 위로 드는 동작에서 가장 흔한 것은 회전근개 관련 통증이고, 앆에 더해 뒤로 내리는 방식과 몸통 고정 문제를 따로 본다.

| 패턴 | 단서 | 근거 강도 | 앱이 하는 말 |
| --- | --- | --- | --- |
| 회전근개 관련 통증 | 어깨 앞·옆 통증, 중간 높이에서만 아픔(통증 호), 아픈 쪽으로 누우면 아픔 | 중간 | "가장 흔한 패턴이에요. 운동으로 좋아지는 경우가 많아요" |
| 쇄골 끝 관절 통증 | 어깨 위 한 점, 팔을 끝까지 올렸을 때 아픔 | 약함 | "무게를 줄이고, 계속되면 확인받으세요" |
| 뒤로 내리는 프레스 부담 | 목 뒤로 바를 내림, 목과 어깨 사이 통증 | 중간 | "앞으로 내리는 방식으로 바꿔 보세요" |
| 몸통·날개뼈 고정 문제 | 허리가 크게 젖혀짐, 어깨가 귀 쪽으로 솟음, 팔이 머리 위로 다 안 올라감 | 중간 | "자세와 보조운동이 도움이 될 수 있어요" |

**근거 메모**

- 어깨 충돌성 통증은 어깨·삼각근 부위 통증, 머리 위 자세에서 악화, 아픈 쪽으로 누우면 아픔, 팔을 옆으로 들 때 중간에서 아픈 통증 호가 특징이다. 쇄골 끝 관절은 그 자리를 누르면 아프고, 팔을 끝까지 올릴 때(높은 호) 아프다 ([KISS 요약](https://api.nbmedical.com/file/28a1e6ed-f590-4136-9cd5-3fc1b2f04263/kiss-shoulder-pain.pdf)). 앱은 직접 눌러보게 하지 않고 아픈 높이만 묻는다.
- 견갑 움직임은 어깨 충돌 증상에 특히 영향을 주지만, 원인인지 결과인지는 아직 분명하지 않다. 상부승모근이 과하게 일하면 어깨를 으쓱하는 모습으로 보인다 ([Kibler 2013](https://bjsm.bmj.com/content/47/14/877)). 오버헤드 종목 선수에서 견갑 운동이상은 이후 어깨 통증 위험과 관련이 있었다 ([Hickey 2018](https://bjsm.bmj.com/content/52/2/102)).
- 숙련자 33명을 분석한 연구에서, 뒤로 내리는 프레스는 바가 머리를 피하도록 고개를 앞으로 숙여 목이 더 굽고 더 돌아갔다. 남성은 뒤로 내릴 때 어깨 바깥회전이 자기 수동 가동범위를 넘었다. 저자들은 가동범위를 먼저 늘리고 하라고 권했고, 목 문제가 있는 사람은 주의하라고 했다. 다만 몸통 안정과 가동범위가 충분하면 두 방식 모두 안전하다고 결론지었다. 다치지 않은 사람만 대상이었다 ([McKean 2015](https://research.usc.edu.au/esploro/outputs/journalArticle/Overhead-shoulder-press--In-front-of/99448807302621)).
- 같은 연구에서 등받이 없이 앉아서 하는 프레스는 몸통 고정이 필요했고, 여성은 허리 움직임이 더 컸다 (McKean 2015). 등을 폈 자세에서 어깨를 더 높이 올릴 수 있다는 강한 근거가 있지만, 한 번 측정한 연구들이다 ([Barrett 2016](https://www.pubmed.gov/27475532/)).
- 통증 호는 팔을 옆으로 들 때 60\~120° 사이 어깨 위쪽이 아프면 양성으로 본다. 수술 진단과 비교한 55명 연구에서 민감도 0.75, 특이도 0.67, 양성 우도비 2.25였고, 검사자 간 일치도는 중간\~상당 수준이었다 ([Michener 2009](https://doi.org/10.1016/j.apmr.2009.05.015), 충남대 도서관 본문). 메타분석에서는 양성 우도비 2.25(민감도 0.53, 특이도 0.76)로, 검사 하나만으로는 진단 확률을 크게 바꾸지 못했다 ([Hegedus 2012](https://upload.orthobullets.com/journalclub/free_pdf/22773322_BrJSportsMed-2012-Hegedus-bjsports-2012-091066.pdf)). 그래서 앱은 통증 호를 회전근개 패턴의 여러 단서 중 하나로만 쓴다. 두 연구 모두 진료실에서 검사자가 한 검사라, 사용자가 혼자 해 보는 것과는 다르다.
- 웨이트 트레이닝 부상의 22\~36%가 어깨에서 생겼다. 팔을 벌리고 바깥으로 돌린 자세("하이파이브 자세")에서 아픈 헬스인 사례가 보고됐고, 목 뒤로 내리는 프레스가 이 자세를 만든다. 고찰들은 바를 몸 앞으로 내리라고 권하지만, 근거는 사례 보고와 서술적 고찰 수준이다 ([Kolber 2010](https://paulogentil.com/pdf/Shoulder%20Injuries%20Attributed%20to%20Resistance%20Training%20-%20A%20Brief%20Review.pdf), [Bonilla 2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC9565175/)).

## 4단계: 바로 해볼 조정

벤치와 같이 답에 맞는 조정 2\~3개를 골라 보여주고, 다음 운동 후 "덜 아팠다 / 같았다 / 더 아팠다"를 기록하게 한다.

| 조정 | 방법 | 추천 조건 | 근거 | 강도 |
| --- | --- | --- | --- | --- |
| 앞으로 내리는 프레스로 바꾸기 | 바를 목 뒤가 아니라 턱 앞·윗가슴 쪽으로 내리기 | 3번이 바벨 뒤로 | 뒤로 내리면 남성의 바깥회전이 수동 가동범위를 넘었고 목이 더 굽었다 ([McKean 2015](https://research.usc.edu.au/esploro/outputs/journalArticle/Overhead-shoulder-press--In-front-of/99448807302621)) | 중간 |
| 무게와 횟수 낮추기 | 통증 없이 할 수 있는 무게로 2주 | 모두 | 보존적 관리의 기본 원칙 ([BESS/BOA](https://pmc.ncbi.nlm.nih.gov/articles/PMC7905504)) | 중간 |
| 갈비뼈를 내리고 배에 힘주기 | 밀 때 허리를 젖히지 않도록 배와 엉덩이에 힘을 주고, 오래 어렵다면 등받이가 있는 벤치를 써 보기 | 5번이 예·모름 | 등받이 없는 앉은 프레스는 몸통 고정이 필요했다 (McKean 2015). 등받이 추천은 연구 결과를 바탕으로 한 추론 | 약함 |
| 등 펴기와 가동성 | 폼롤러에 등을 대고 윗등 펴기, 벽 앞 어깨 스트레칭 | 6번이 간신히·안 닿음 | 등을 폈 자세에서 어깨를 더 높이 올릴 수 있었다 ([Barrett 2016](https://www.pubmed.gov/27475532/)). 어깨 뒤쪽 뿣뿣함도 날개뼈를 앞으로 끌 수 있다 ([Kibler 2013](https://bjsm.bmj.com/content/47/14/877)) | 중간 |
| 회전근개·날개뼈 운동 추가 | 밴드 외회전, 엎드려 Y자로 팔 들기 등 하부승모근·전거근 운동 | 10번이 안 함·가끔, 또는 7번이 예 | 운동치료는 어깨 충돌성 통증의 1차 치료 ([Pieters 2020](https://repository.uantwerpen.be/docman/irua/187b87/163966_2020_05_18.pdf)). 상부승모근은 덜 쓰도록 (Kibler 2013) | 강함 |
| 그립을 중간 너비로 (추가) | 손 간격을 어깨너비 약 1.4배로 | 3-1번이 그보다 넓게 | 넓은 그립(1.7배)은 어깨 회전력을 키웠고, 좁은 그립(1.0배)은 어깨 부담은 줄었지만 어깨 벌림 범위가 커졌다. 무손상 숙련자 11명 (Gundersen 2026, 충남대 도서관 본문) | 약함 |

통증 호가 있는 사람에게 "그 높이를 피하라"는 조정은 넣지 않았다. 본문을 확인한 자료 중에 이를 뒷받침하는 근거가 없다.

## 5단계: 전문가 연결

벤치 어깨와 같은 기준을 쓴다. 조정 2주 후에도 그대로이거나 나빠지면 정형외과·재활의학과, 일상에서도 아프거나 6주 이상이면 진료가 먼저다.

영국 1차 진료 요약은 어깨 충돌성 통증이 운동치료로 좋아지는 데 6\~12주 걸린다고 미리 알려주고, 6\~12주에도 나아지지 않으면 의뢰하라고 한다 ([KISS 요약](https://api.nbmedical.com/file/28a1e6ed-f590-4136-9cd5-3fc1b2f04263/kiss-shoulder-pain.pdf)). 앱의 2주는 이보다 일찍 "한 번 확인받을 시점"으로 둔 것이다.
