# C11 전문가 검토 사례: "진료 먼저" 조건과 운동 조정의 관계

콘텐츠 버전 8.2 기준. 아래 결과는 앱을 실제로 실행해서 뽑은 것이다(다시 만들 때는 Claude에게 요청).
**판단 규칙은 바꾸지 않았다.** 전문가 의견을 받은 뒤 결정한다.

## 지금 앱의 두 가지 처리 방식

1. **진료 먼저 변수가 결과에 나오는 경우 (A):** 변수 제목이 "… → 진료 먼저"인 경우다. 이때는 **조정을 보여주지 않는다**(v8.1부터).
2. **일반 진료 먼저 조건만 해당하는 경우 (B):** 일상에서도 아픔, 6주 이상, 나빠지는 중, 무릎 붓기, 고관절 걸림·잠김 같은 조건이다. 이때는 결과 맨 위에 "진료를 먼저 권해요"를 띄우고, **조정도 "참고만 하라"며 함께 보여준다**(v7부터 같은 방식).

## B. 진료를 먼저 권하면서 조정도 보여주는 경우

| 사례 | 주제 | 바꾼 답 (나머지는 예시 답변) | 앱이 보여주는 점검 변수 | 진료 먼저 안내 | 보여주는 조정 |
| --- | --- | --- | --- | --- | --- |
| B1 운동 안 할 때·일상에서도 아픔 (데드리프트) | 데드리프트 | 언제 가장 아픈가요? → 운동 안 할 때, 일상에서도 | 허리에 걸리는 전체 운동 부하 / 최근 훈련량 급증 | 운동하지 않을 때도 아프고 있어요. 아래 조정은 참고만 하고, 정형외과나 재활의학과에서 먼저 확인받으세요. | 무게와 횟수 낮추기 / 끊지 말고 가볍게 다시 늘리기 |
| B2 6주 이상 지속 (벤치) | 벤치프레스 | 아픈 지 얼마나 됐나요? → 6주 이상 | 바를 내리고 미는 동작의 어깨 부담 / 무겁게·자주 하는 벤치의 어깨 위쪽 부담 / 날개뼈 세팅과 보조운동 | 6주 넘게 계속되고 있어요. 아래 조정은 참고만 하고, 정형외과나 재활의학과에서 먼저 확인받으세요. | 그립을 어깨너비 1~1.5배로 / 날개뼈 모으고 내리기 / 어깨·날개뼈 보조운동 더하기 |
| B3 나빠지는 중 (숄더 프레스) | 숄더 프레스 | 요즘 통증은 어떻게 변하고 있나요? → 나빠지는 중 | 팔을 머리 위로 올리는 구간의 어깨 부담 / 목 뒤로 내리는 바 경로 / 몸통·날개뼈 고정 | 점점 나빠지고 있어요. 아래 조정은 참고만 하고, 정형외과나 재활의학과에서 먼저 확인받으세요. | 앞으로 내리는 프레스로 바꾸기 / 어깨·날개뼈 보조운동 더하기 / 갈비뼈를 내리고 배에 힘주기 |
| B4 운동 후 무릎이 붓는다 (위치는 무릎뼈 주변) | 스쿼트·런지·레그프레스 (무릎) | 운동 후 무릎이 붓나요? → 예 | 무릎을 깊이 굽혀 체중을 싣는 구간의 무릎 앞 부담 | 무릎이 붓거나 안·바깥쪽이 아프고 있어요. 아래 조정은 참고만 하고, 정형외과나 재활의학과에서 먼저 확인받으세요. | 아프지 않은 깊이까지만 앉기 / 엉덩이·무릎 근력 운동 함께 하기 / 엉덩이를 뒤로 빼고 상체를 조금 숙이기 |
| B5 고관절 '딸깍'·걸림·잠김 | 스쿼트·런지·레그프레스 (고관절) | 고관절에서 "딸깍" 걸리거나, 잠기거나, 힘이 빠지는 느낌이 드나요? → 예 | 고관절을 깊이 접는 구간의 사타구니 부담 | 고관절이 걸리거나 잠기는 느낌, 또는 엉덩이 바깥쪽 통증이 있고 있어요. 아래 조정은 참고만 하고, 정형외과나 재활의학과에서 먼저 확인받으세요. | 아프지 않은 깊이까지만 앉기 / 고관절·몸통 근력 운동 3개월 이상 / 운동은 끊지 말고 줄여서 이어가기 |
| B6 달리지 않을 때(걷기·밤)도 아픔 | 달리기 (무릎·정강이) | 달리지 않을 때(걷기, 밤)에도 아픈가요? → 예 | 달리기·계단에서 무릎 앞에 걸리는 부담 | 운동하지 않을 때도 아프고 있어요. 아래 조정은 참고만 하고, 정형외과나 재활의학과에서 먼저 확인받으세요. | 엉덩이·무릎 근력 운동 / 달리는 양 줄이고 천천히 늘리기 / 보폭 줄이고 발걸음 수 5~10% 늘리기 |

## 참고: v8.2에서 바꾼 표시 하나

A 사례에서는 조정이 없는데도 안내 문구에 "아래 조정은 참고만 하고"가 붙어 있었다. 판단 규칙은 그대로 두고, 조정이 없을 때는 이 문장이 나오지 않게 화면 문구만 고쳤다.
