# 컬·풀업 팔꿈치 통증 자가점검 기획서

Nov 6, 2026 · @하민규

## 개요와 위험 신호

팔꿈치는 새 부위다. 아픈 위치로 바깥쪽(외측상과, 테니스 엘보), 안쪽(내측상과, 골프 엘보), 앞쪽(이두근 힘줄)을 나눈다. 도서관 미확인이다.

| 질문 (예/아니오) | 의심되는 상황 | 앱 안내 |
| --- | --- | --- |
| 넣어지거나 부딪힌 뒤 팔꿈치가 붓고 펴거나 굽히기 어렵나요? | 골절·탈구 | 오늘 응급실 |
| 열이 나고 팔꿈치가 붉고 뜨겁게 붓었나요? | 감염 | 오늘 응급실 |
| 무거운 걸 들다가 "뚝" 하고, 팔꿈치 앞에 멍이 들거나 알통 모양이 변하거나 손바닥을 뒤집는 힘이 약해졌나요? | 이두근 원위힘줄 파열 | 며칠 안에 정형외과 |
| 넷째·다섯째 손가락이 저리거나 감각이 둔하고, 손 힘이 약해졌나요? | 척골신경 압박 | 빠른 시일 내 진료 |
| 목이 아프면서 저림이 팔꿈치 아래로 내려가나요? | 목에서 오는 통증 | 빠른 시일 내 진료 |

- **논문 확인**: 이두근 원위힘줄 파열은 팔꿈치가 강제로 펴지는 순간 이두근이 힘을 주고 있을 때 생기고, 웨이트 트레이닝·스테로이드 사용이 위험 요인이다. "뚝" 하는 느낌, 팔 아래쪽 멍, 알통 모양 변화, 손바닥 뒤집기 약화가 단서다. 치료가 늦으면 합병증 위험이 커져 일찍 결정하라고 권한다 ([Alentorn-Geli 2016](https://pmc.ncbi.nlm.nih.gov/articles/PMC5367534)).
- **논문 확인**: 넷째·다섯째 손가락 저림은 척골신경 문제와 관련이 있다 ([Konarski 2022](https://rcastoragev2.blob.core.windows.net/52b7d0b21ff50062bf7562cd326c0fb1/PMC9407887.pdf)). 목 디스크·신경 문제는 팔꿈치 바깥쪽 통증의 감별 진단이다 ([Lucado 2022 JOSPT CPG](https://www.orthopt.org/uploads/content_files/files/jospt.2022.0302.pdf)).
- **검증 안 된 가설**: 골절·감염 문항은 이번에 본 팔꿈치 자료에 따로 없어서, 다른 부위 주제의 일반 원칙을 옮겨 온 것이다. 시간 구분도 앱이 정했다.

## 질문과 패턴

| # | 질문 | 선택지 |
| --- | --- | --- |
| 1 | 어디가 아픈가요? | 팔꿈치 바깥쪽 / 안쪽 / 앞쪽(오금) / 모름 |
| 2 | 어떤 운동에서 아픈가요? | 바벨·덤벨 컬 / 풀업·랫풀다운 / 둘 다 / 기타 |
| 3 | 물건을 꽉 쥐거나 문고리를 돌릴 때도 아픈가요? | 예 / 아니오 |
| 4 | 손바닥을 아래로 하고 팔을 편 채 무거운 걸 들면 아픈가요? | 예 / 아니오 |
| 5 | 어떻게 시작됐나요? | "뚝" 하며 갑자기 / 서서히 |
| 6 | 최근 4주 사이 무게·횟수를 크게 늘렸나요? | 예 / 아니오 |
| 7 | 아프고 나서 운동은? | 쉬고 있음 / 가볍게 계속 / 원래대로 |
| 8·9 | 기간, 경과 | 다른 주제와 같음 |

| 패턴 | 단서 | 근거 강도 |
| --- | --- | --- |
| 팔꿈치 바깥쪽 힘줄 통증 | 바깥쪽, 쥐기·손바닥 아래 들기에서 아픔 | 중간 |
| 팔꿈치 안쪽 힘줄 통증 | 안쪽, 쥐기에서 아픔 | 약함 |
| 팔꿈치 앞쪽 통증 | 앞쪽(오금), 특히 갑자기 시작 | 약함 (진료 먼저) |

- **논문 확인**: 바깥쪽 힘줄 통증은 외측상과 국소 통증이 누르기·손목·손가락 펴기 저항으로 재현되는 것으로 진단한다. 최대 55%가 2년 넘게 통증이 남았다 (Lucado 2022).
- **논문 확인**: 안쪽 통증은 바깥쪽보다 7\~10배 드물고, 손목 굽힘·아래팔 내회 저항 검사가 가장 민감하다. 70%는 서서히 시작된다 (Konarski 2022, 서술적 리뷰).
- **검증 안 된 가설**: 3·4번처럼 스스로 해 본 동작으로 패턴을 고르는 것과, 앞쪽 통증을 진료 먼저로 보내는 것은 앱의 규칙이다. 앞쪽 통증의 흔한 원인(이두근 힘줄병증 등)은 이번에 조사하지 못했다.

| 손목 펴기 저항 운동 (버티기 → 들기 → 천천히 내리기) | 바깥쪽 패턴 | 아급성·만성 바깥쪽 힘줄 통증에 손목 펴기 저항 운동(등척성·동심성·편심성)을 권고 (등급 B, Lucado 2022) | 운동 순서·횟수 예시는 앱의 선택 | 중간 |
