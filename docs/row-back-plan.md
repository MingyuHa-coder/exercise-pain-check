# 바벨 로우 허리 통증 자가점검 기획서

Nov 6, 2026 · @하민규

## 개요와 위험 신호

숙여서 당기는 바벨 로우에서 허리가 아픈 경우다. 앱에서는 등 → 바벨 로우 → 허리로 들어온다. 허리 통증 자체의 근거(위험 신호, 경과, 활동 유지)는 데드리프트 주제와 같아서 그대로 가져왔고, 로우에 특화된 근거는 Fenwick 2009 하나다. 로우 중 허리가 아픈 사람을 다룬 연구는 찾지 못했다.

위험 신호는 데드리프트 주제와 같은 6문항이다(마미증후군, 진행성 근력 약화 → 지금 응급실 / 골절·감염 → 오늘 응급실 / 암·다리 저림 → 빠른 진료, [Finucane 2020](https://core.ac.uk/download/387934007.pdf)). 무릎 아래로 내려가는 다리 증상이면 조정 없이 진료를 먼저 권한다(데드리프트와 같은 앱의 보수적 선택).

## 질문·패턴·조정과 근거 목록

**질문 10개**: 아픈 곳, 다리 증상, 시작 방식(데드리프트와 같음), 가장 아플 때(숙인 자세 버틸 때 / 당길 때 들썩일 때 / 운동 후 / 일상에서도), 로우 방식(서서 바벨 / 펜들레이 / 한 손 짚고 덤벨 / 가슴 받침·앉아서), 상체 들썩임, 최근 4주 급증, 아픈 뒤 로우, 기간, 경과.

| 패턴 | 단서 | 근거 강도 |
| --- | --- | --- |
| 비특이적 허리 통증 | 기본 | 강함 (데드리프트와 공통) |
| 숙인 자세 버티기 부담 | 서서 하는 로우 + 버틸 때·들썩일 때 | 약함 |
| 훈련 부하 급증 | 최근 4주 급증 | 약함 |
| 신경 뿌리 자궹 가능성 | 무릎 아래 다리 증상 → 진료 먼저 | 중간 |

| 조정 (앱 제안) | 논문 확인 | 검증 안 된 가설 | 강도 |
| --- | --- | --- | --- |
| 가슴을 받치는 로우로 바꾸기 (체스트 서포티드, 한 손 짚는 덤벨, 앉아서 케이블·머신) | 서서 하는 바벨 로우 허리 압박 3,576N vs 인버티드 로우 2,339N, 한 손 케이블 로우 2,457N. 허리 굽힘도 바벨 로우가 가장 컨다(범위의 42.9%). 저자들은 부하를 덜 견디는 사람에게 인버티드 로우를 제안 (건강한 남성 7명, Fenwick 2009) | 가슴 받침·앉은 로우는 측정되지 않음, 통증 효과 미확인 | 약함 |
| 반동 없이 상체 고정하기 | 저자들은 중립 척추를 지키는 엄격한 자세를 강조 (Fenwick 2009) | 반동과 통증의 관계 미연구 | 약함 |
| 무게와 횟수 낮추기 | 허리를 다친 파워리프터 대부분은 훈련량·강도를 줄여 이어감 (Strömbäck 2018) | "2주" | 약함 |
| 다른 운동으로 계속 움직이기 | 활동 유지·운동 프로그램 권고 (NICE NG59) | 운동 예시 | 중간 |
