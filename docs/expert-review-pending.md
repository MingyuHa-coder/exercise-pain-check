# 전문가 검토 대기 목록

어깨 자가점검 앱에서 **논문 근거 없이 Claude가 임의로 설계한 부분**을 모아 둔 목록이다. 나중에 전문가 검토를 한 번에 받을 때 이 목록을 그대로 보여주면 된다.

- 최종 정리: 2026-11-05
- 대상: 벤치프레스 어깨, 숄더 프레스 어깨, 데드리프트 허리, 스쿼트 무릎, 스쿼트 허리 (같은 앱)
- 표시: 🔴 = 결과에 직접 영향, 반드시 검토 / 🟡 = 표현·화면, 가볍게 확인

## 1. 두 주제 공통

| # | 내용 | 임의로 정한 부분 | 중요도 |
|---|---|---|---|
| C1 | 패턴 점수 규칙 | 답변마다 점수(+1~+4)를 주고, 점수가 높은 쪽을 "가장 가까운 패턴"으로 고른다. 점수 크기와 기준선(예: 3점 이상이면 함께 보이는 패턴)은 모두 임의 | 🔴 |
| C2 | 조정 우선순위 | 조건에 맞는 조정 중 우선순위 상위 3개만 보여준다. 우선순위 숫자는 임의 | 🔴 |
| C3 | "2주" 확인 시점 | 조정 2주 뒤에도 그대로·나빠지면 진료 권유. 가이드라인(KISS)은 6~12주로 보는데, 앱은 더 일찍 "한 번 확인받을 시점"으로 정함 | 🔴 |
| C4 | 진료 먼저 권유 조건 | 일상에서도 아픔 / 6주 이상 / 나빠지는 중 중 하나면 조정보다 진료를 먼저 권함. 조합 방식은 임의 | 🔴 |
| C5 | 덜·같·더 기록 해석 | "덜 아팠어요 → 나에게 맞는 단서", "같았어요 → 2주 지켜보기", "더 아팠어요 → 멈추고 확인" 문구 | 🟡 |
| C6 | 위험 신호 문구 | 가이드라인의 위험 신호를 일반인용 질문으로 바꾼 표현, "며칠 안에"·"빠른 시일 내" 같은 시간 표현 | 🔴 |
| C7 | 전문가 연결 표 | 상황별로 정형외과·재활의학과·물리치료·트레이너 중 어디로 갈지 나눈 기준 | 🟡 |
| C8 | 질문 문구 전반 | 의학 용어를 쉬운 말로 바꾼 표현 (예: 쇄골 끝, 날개뼈) | 🟡 |

| B4 | 팔꿈치 각도 그림 | 45°·70°·90°를 위에서 본 그림으로 표현. 그림 자체는 직접 그린 것 | 🟡 |

## 3. 숄더 프레스

| # | 내용 | 임의로 정한 부분 | 중요도 |
|---|---|---|---|
| O1 | 벽 팔 올리기 확인 동작 (6번) | 뒤통수·등·엉덩이를 벽에 붙이고 팔을 올려 엄지가 닿는지 보는 동작. 검증된 검사가 아니라 앱이 만든 것 | 🔴 |
| O2 | 통증 호를 사용자 혼자 해 보는 것 | 60~120° 기준은 Michener 2009로 확인됨. 다만 연구는 진료실에서 검사자가 한 것이라, 사용자가 혼자 해도 같은 의미인지는 근거 없음 | 🟡 |
| O3 | 직접 해 보는 문항 (2번, 6번) | 아픈 사람에게 동작을 시켜도 되는지, "아프면 멈추세요" 안내로 충분한지 | 🔴 |
| O4 | 목과 어깨 사이 통증 → 뒤로 내리는 프레스 부담 | McKean은 목이 더 굽는다고 했지만, 목 통증을 이 패턴의 단서로 쓰는 것은 추론 | 🔴 |
| O5 | 어깨가 귀 쪽으로 솟음 → 날개뼈 문제 | Kibler 2013의 상부승모근 과활성 설명을 일반인 관찰 질문으로 바꾼 것 | 🟡 |
| O6 | 등받이 있는 벤치 추천 | McKean 결과(등받이 없는 앉은 프레스는 몸통 고정 필요)를 바탕으로 한 추론 | 🟡 |
| O7 | 급성 회전근개 파열 위험 신호 문구 | "다친 뒤 아프지 않은데도 팔을 어깨 높이 위로 들 힘이 없나요?" 일반인이 이해하고 정확히 답할 수 있는지 | 🔴 |
| O8 | 앞으로 내리는 프레스 바꾸기를 1순위로 | 목 뒤로 내리는 사람에게 가장 먼저 보여줌. 순서는 임의 | 🟡 |
| O9 | 그립 너비 문항과 "중간 너비(1.4배)" 추천 | Gundersen 2026은 건강한 11명의 관절 부하만 봤음. 넓은 그립을 쓰는 아픈 사람에게 1.4배를 권하는 연결은 추론 | 🟡 |
| O10 | "어깨보다 주먹 하나씩 넓게" 설명 | 1.4배를 일반인이 알기 쉽게 바꾼 표현. 실제 1.4배와 맞는지 확인 필요 | 🟡 |

## 4. 데드리프트

| # | 내용 | 임의로 정한 부분 | 중요도 |
|---|---|---|---|
| D1 | 위험 신호 안내 단계 | 마미증후군·진행성 근력 약화 → "지금 바로 응급실", 골절·감염 → "오늘 응급실", 암·다리 저림 → "빠른 진료". Finucane 2020은 응급·긴급 의뢰를 말하지만 시간 구분 문구는 앱이 정함 | 🔴 |
| D2 | 무릎 아래 다리 저림을 위험 신호·"진료 먼저"에 넣은 것 | 앱의 보수적 선택. 좌골신경통 대부분은 응급이 아님 | 🔴 |
| D3 | "최근 4주 사이 크게 늘렸나요?" 문항 | 4주, "크게"의 기준은 근거 없음 | 🟡 |
| D4 | 훈련 부하 급증 패턴 | Strömbäck 2018은 설문이라 원인 판단 불가. 급증·주 3회 이상으로 패턴을 고르는 규칙은 앱이 만듦 | 🔴 |
| D5 | "끊지 말고 가볍게 다시 늘리기"를 혼자 하게 하는 것 | Michaelson 2016은 물리치료사가 지도한 프로그램. 혼자 해도 안전·효과적인지 확인 필요 | 🔴 |
| D6 | 트랩바 추천 | 근활성도 차이(건강한 사람)를 통증 조정으로 연결한 추론. 원 논문(Camara 2016)은 직접 못 읽음 | 🟡 |
| D7 | "허리를 굽히면 다치나요?" 설명 카드 | Saraceni 2020은 12kg 이하 들기 연구. 무거운 데드리프트에 적용하는 표현이 적절한지 | 🟡 |

## 5. 스쿼트 무릎

| K4 | 무릎 안·바깥쪽 통증과 운동 후 붓기를 "진료 먼저"로 | 스쿼트 관련 근거가 없어 앱이 보수적으로 정함 | 🔴 |
| K5 | "통증 5/10, 다음 날 회복" 기준을 슬개대퇴 통증에도 적용 | Rosen 2022는 무릎힘줄 통증 기준 | 🟡 |
| K6 | 엉덩이 위주 스쿼트를 허리 통증 없는 사람에게만 | 허리 부담 증가 우려에 따른 앱의 판단 | 🟡 |

## 검토 받을 때 물어볼 질문 (요약)

1. 위험 신호 6문항과 안내 단계(119 / 응급실 / 며칠 안 정형외과 / 빠른 진료)가 적절한가?
2. 조정 후 "2주"에 한 번 확인받으라는 기준이 너무 이르거나 늦지 않은가?
3. 숄더 프레스 2번(팔 옆으로 들기)과 6번(벽 팔 올리기)을 아픈 사람에게 직접 해 보게 해도 되는가?
6. 데드리프트: 허리 통증이 있는 사람에게 혼자서 "가볍게 다시 늘리기"를 권해도 되는가? 위험 신호 시간 구분은 적절한가?
4. 패턴 점수 규칙이 임상적으로 말이 되는가? (앱 코드의 RULES 부분 함께 보여주기)
5. 쉬운 말로 바꾼 질문 문구가 원래 의미를 해치지 않는가?
7. 스쿼트 무릎: 스스로 답한 단서로 슬개대퇴 통증과 무릎힘줄 통증을 나눠도 되는가? 붓기·안바깥쪽 통증을 진료 먼저로 보낸 기준은 적절한가?
