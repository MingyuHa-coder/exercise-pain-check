# 전문가 검토 대기 목록

운동 통증 점검 앱에서 **논문 근거 없이 Claude가 임의로 설계한 부분**을 모아 둔 목록이다. 나중에 전문가 검토를 한 번에 받을 때 이 목록을 그대로 보여주면 된다. 맨 아래 "검토 기록"에 기획서 7-5 양식으로 검토 결과를 남긴다.

- 최종 정리: 2026-11-06 (콘텐츠 버전 7)
- 대상: 13개 주제 — 벤치프레스 어깨, 숄더 프레스 어깨, 레터럴 레이즈·업라이트 로우 어깨, 딥스·푸시업 어깨, 풀업·랫풀다운 어깨, 데드리프트 허리, 스쿼트 허리, 바벨 로우 허리, 스쿼트·런지·레그프레스 무릎, 스쿼트·런지 고관절, 컬·풀업 팔꿈치, 딥스·벤치·푸시업 손목, 달리기 무릎·정강이
- 표시: 🔴 = 결과에 직접 영향, 반드시 검토 / 🟡 = 표현·화면, 가볍게 확인
- 2026-11-06: 🟡 항목은 모두 전문가 검토를 마쳤다(✅). 고친 것은 C7(전문가 연결은 정형외과·재활의학과 위주로)과 D7(12kg 이하 들기 연구를 데드리프트에 적용하지 않기) 두 가지다. 앱에는 검토를 마친 항목에 "전문가 검토 완료", 고친 항목에 "전문가 검토 의견 반영" 표시를 붙였다.
- 2026-11-06: 손목(W)·달리기(R) 항목에 중요도를 새로 매겼다. 이 항목들은 아직 검토 전이다(✅ 없음). W2는 비슷한 E5(팔꿈치 앞쪽 → 진료 먼저)처럼 진료 쪽으로 보내는 보수적 선택이라 🟡로 두었다.
- 2026-11-06 (v7): 사업 기획서에 맞춰 앱 구조를 바꿨다. ① 결과를 질환명 대신 "점검할 운동 변수"로 보여준다(연구에서 쓰는 이름은 접어서 참고로만). 위험 신호 안내 문구에서도 의심 질환명을 뺐다. ② 사용자가 직접 해 보는 검사 동작을 없애고 "최근에 겪은 일"을 묻는 질문으로 바꿨다(O1·O2·O3·E3). ③ 벤치 B1 규칙을 없애고 상완골 전방활주 카드는 누구나 보는 설명으로 바꿨다. ④ W5의 보조기·57% 내용은 "근거 자세히" 안쪽으로 옮겼다. ⑤ 답이 모호할 때의 결과(C9)와 근거 수준 표시(C10)를 새로 만들었다. ⑥ 화면·규칙·콘텐츠를 파일로 나눴다(규칙은 `content/topics/*.js`의 analyse).

## 9. 딥스·벤치·푸시업 손목 (도서관 미확인)

무료 공개 자료만 확인했다. 헬스인의 손목 통증을 직접 다룬 연구는 찾지 못했다.

| 번호 | 앱이 정한 것 | 근거 상태 | 검토 질문 | 중요도 |
