# 딥스·푸시업 어깨 통증 자가점검 기획서

Nov 6, 2026 · @하민규

## 개요와 위험 신호

가슴 운동 중 딥스(바 딥스·벤치 딥스)와 푸시업에서 어깨가 아픈 경우다. 앱에서는 가슴 → 딥스/푸시업 → 어깨로 들어온다. 충남대 도서관 포함 조사(Ludewig 2004는 도서관 본문).

위험 신호는 벤치프레스 주제의 어깨 공통 5문항(심장·폐, 탈구, 감염, 밤새 통증·혹·체중 감소, 팔 저림)에 대흉근 파열 문항을 더했다.

| 추가 문항 | 의심 | 안내 |
| --- | --- | --- |
| 딥스나 푸시업 중 "뚝" 하는 느낌과 함께 가슴·겨드랑이 앞이 아프고 힘이 빠졌나요? 멍·겨드랑이 앞 모양 변화 | 대흉근 파열 | 며칠 안 정형외과 |

- **논문 확인**: 대흉근 파열은 벤치프레스 외에 바 딥스·체스트 플라이에서도 보고됐다(증례 보고·증례 메타분석 인용) ([Kolber 2010](https://paulogentil.com/pdf/Shoulder%20Injuries%20Attributed%20to%20Resistance%20Training%20-%20A%20Brief%20Review.pdf)).
- **논문 확인**: 바 딥스 연구 저자들은 무게를 달거나 지치거나 손을 넓게 잡으면 대흉근 부상 위험이 커질 수 있다고 했다 ([McKenzie 2022a](https://doi.org/10.3390/ijerph192013211)).
- **검증 안 된 가설**: "며칠 안 정형외과"라는 시간 표현은 벤치 주제와 같이 앱이 정했다.

## 질문·패턴·조정과 근거 목록

**질문 9개**: 아픈 곳(어깨 앞 / 쇄골 끝 / 바깥·깊은 곳 / 가슴·겨드랑이 앞 근육), 운동(바 딥스 / 벤치 딥스 / 푸시업 / 둘 다), 가장 아플 때(바닥 / 밀어 올릴 때 / 끝난 뒤 / 팔을 옆으로 들 때도), 딥스 깊이(평행 전 / 평행 / 더 깊이), 푸시업 팔꿈치 벌림(T자 / 45° / 붙임), 최근 4주 급증, 기간, 경과, 보조운동.

| 패턴 | 단서 | 근거 강도 |
| --- | --- | --- |
| 깊이 내려갈 때 어깨 앞쪽 부담 | 평행보다 깊이, 벤치 딥스, 바닥에서 아픔 | 약함 |
| 팔꿈치를 벌린 푸시업 부담 | 팔꿈치 T자 | 약함 |
| 회전근개 관련 통증 | 바깥·깊은 곳, 팔을 옆으로 들 때도 | 중간 (벤치·숙더 주제와 공통) |
| 쇄골 끝 관절 통증 | 어깨 위쪽 한 점 | 약함 (벤치 연구를 옮김) |
| 가슴 근육·힘줄 부담 | 가슴·겨드랑이 앞 | 약함 |

| 조정 (앱 제안) | 논문 확인 | 검증 안 된 가설 | 강도 |
| --- | --- | --- | --- |
| 딥스 깊이 줄이기 (위팔이 바닥과 평행해지기 전까지) | 바·벤치 딥스는 어깨를 최대 범위의 88\~101%까지 뒤로 젖힌다 (건강한 남성 13명, McKenzie 2022a) | "평행 전까지" 기준, 통증 감소 효과 | 약함 |
| 벤치 딥스는 다른 운동으로 | 저자들은 벤치 딥스를 일반 근력 운동·재활에 넣지 말라고 했고, 바 딥스는 도움·밴드로 하는 쉬운 단계를 권했다 (McKenzie 2022a) | 아픈 사람에게 바꾼 효과 | 약함 |
| 푸시업 팔꿈치 모으기 (45° 정도) | 위팔 60° 넘게 벌리지 말고 편한 위치나 몸통 가까이를 권함 (건강한 16명, Suprak 2013) | "45°" 표현, 통증 효과 | 약함 |
| 푸시업 플러스 | 가벼운 어깨 문제가 있는 사람 포함 30명에서 앞톱니근 활성 최대(123%), 위쪽 승모근 비율 낮음(<0.2) (Ludewig 2004, 도서관 본문) | 통증 감소는 보지 않음 | 중간 |
| 무게·횟수 줄이기 | 어깨 통증 보존적 관리의 기본 (BESS/BOA 2021) | "2주" | 중간 |
| 회전근개·날개뼈 운동 | 어깨 충돌성 통증의 1차 치료 (Pieters 2020) | 운동 예시 | 강함 |
