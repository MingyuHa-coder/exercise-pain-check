## 개요와 위험 신호

스쿼트·런지·레그프레스에서 사타구니나 고관절이 아픈 경우다. 앱에서는 하체 → 스쿼트/런지/레그프레스 → 고관절·사타구니로 들어온다. 두 국제 합의(Warwick 2016, Doha 2015)와 물리치료 합의(Kemp 2020)가 뼈대다. 세 논문은 무료 본문(출판사·기관 저장소)으로 먼저 확인했고, 사용자 로그인 뒤 도서관판 본문으로 다시 대조해 내용이 같음을 확인했다. Doha 합의의 표 1(놓치면 안 되는 원인)은 도서관판 화면에서 표를 불러오지 못해, 기관 저장소 원고의 표로 확인했다.

| 질문 (예/아니오) | 의심 | 앱 안내 |
| --- | --- | --- |
| 넘어지거나 부딪힌 뒤 고관절이 아프고 체중을 싣고 걷기 어렵나요? | 골절 | 오늘 진료 |
| 열이 나고 고관절이 아파서 다리를 거의 움직이지 못하나요? | 관절 감염 | 오늘 진료 |
| 운동량을 늘린 뒤 사타구니 깊은 곳이 아프고 걸을 때·쉴 때도 아픈가요? | 넙다리뼈 목 피로골절 | 며칠 안 정형외과 |
| 소변 통증·복통·고환·아랫배 붓기·혹 | 비뇨기·복부·종양 등 | 빠른 시일 내 진료 |
| 허리부터 다리로 저림·감각 둔화 | 허리·신경에서 오는 통증 | 빠른 시일 내 진료 |
| 이유 없는 체중 감소, 밤새 계속 아픔 | 종양 등 | 빠른 시일 내 진료 |

- **논문 확인**: Doha 합의는 사타구니 통증에서 놓치면 안 되는 원인으로 넙다리뼈 목·두덱뼈·비구 피로골절, 종양(고환·뼈 등), 감염(고관절염·요로감염), 충수염·요로결석 등을 꼽고, 허리·엉치에서 오는 연관통도 고려하라고 했다 ([Weir 2015](https://eprints.whiterose.ac.uk/id/eprint/110611/1/Doha%20agreement%20meeting%20on%20terminology%20and%20definitions%20in%20groin%20pain%20in%20athletes.pdf)).
- **논문 확인**: 넙다리뼈 목은 피로골절 고위험 부위다 ([Patel 2011](https://www.aafp.org/pubs/afp/issues/2011/0101/p39.html)).
- **검증 안 된 가설**: 일반인용 질문 표현과 "오늘 / 며칠 안 / 빠른 시일" 시간 구분은 앱이 정했다.

## 질문·패턴·조정과 근거 목록

**질문 8개**: 아픈 곳(사타구니 깊은 곳 / 허벅지 안쪽 근육 / 엉덩이 앞 접히는 곳 근육 / 엉덩이 바깥쪽), 운동(스쿼트 / 와이드·스모 / 런지 / 레그프레스), 가장 아플 때(깊이 접힐 때 / 다리가 벌어질 때 / 다리를 들거나 일어날 때 / 일상에서도), 걸림·잠김, 스쿼트 깊이, 최근 4주 급증, 기간, 경과.

| 패턴 | 단서 | 근거 강도 |
| --- | --- | --- |
| 고관절 관련 사타구니 통증 | 사타구니 깊은 곳, 깊이 접힐 때, 걸림 | 중간 (국제 합의) |
| 내전근 통증 | 허벅지 안쪽, 벌어질 때, 와이드 | 약함 |
| 장요근 통증 | 엉덩이 앞, 다리를 들 때 | 약함 |
| 엉덩이 바깥쪽 통증 | 바깥쪽 → 진료 먼저 | 근거 없음 |

"딸깍"·걸림·잠김에 예라고 하면 조정을 보여주되 진료를 먼저 권한다(Warwick 합의는 진단에 영상 필요).

| 조정 (앱 제안) | 논문 확인 | 검증 안 된 가설 | 강도 |
| --- | --- | --- | --- |
| 아프지 않은 깊이까지만 (박스 사용) | 보존적 치료에 활동 조정 포함 (Griffin 2016). 캠형 충돌 15명은 최대 스쿼트 깊이가 얼았고 골반 움직임이 적었다 (Lamontagne 2009) | 깊이를 줄이는 효과는 직접 연구 없음 | 약함 |
| 편한 발 간격·발끝 방향 찾기, 내전근이면 와이드·큰 보폭 줄이기 | 없음 | 전부 앱 제안 | 약함 |
| 고관절·몸통 근력 운동 3개월 이상 | 운동 치료 권고(근거 중간), 3개월 이상이 더 효과적(근거 제한적) (Kemp 2020) | 운동 예시·횟수 | 중간 |
| 운동은 끊지 말고 줄여서 이어가기 | 고관절 관련 통증에도 신체 활동 권고 (Kemp 2020) | "2주" | 약함 |
